# DroneLinkClient

The React/TypeScript DroneLink web interface. Install with `npm ci`, test with `CI=true npm test -- --watchAll=false`, and build with `npm run build`.

See [operations](docs/operations.md) for verified release archives and same-origin hosting, [architecture](docs/architecture.md) for boundaries, and the [documentation index](docs/README.md) for shared contracts and plans.
